# darwin-feed

YML-фид каталога питомника «Сажень» (darwinshop.ru, Томск) для автообновления сайта.

| Файл | Что это |
|---|---|
| `darwinshop.yml` | Рабочий фид: весь каталог, у части позиций — наши описания под условия Томской области |
| `darwinshop-snapshot.yml` | Снимок текущего наполнения сайта без наших переработок. Страховка на откат |

Формат — YML (Yandex Market Language), UTF-8. Ключ сопоставления товара — атрибут `id`
предложения, это Артикул.

Репозиторий существует ради одного: дать постоянную ссылку, по которой сайт забирает фид.
Содержимое генерируется скриптом `scripts/build_yml.py` из проекта darwin_rag и сюда
только выкладывается.
