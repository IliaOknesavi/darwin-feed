# darwin-feed

YML-фид каталога питомника «Сажень» (darwinshop.ru, Томск).

## Ссылка для импортёра

**https://iliaoknesavi.github.io/darwin-feed/darwinshop.xml**

Ссылка постоянная. Содержимое под ней меняется по мере согласования позиций —
переподключать импорт при этом не нужно.

## Что сейчас под ссылкой

**Дословная копия текущего наполнения сайта.** 594 товара: описания, названия,
характеристики и картинки совпадают с darwinshop.ru знак в знак. Сверено программно,
расхождений ноль.

Это сделано намеренно. Сначала переключается механизм — и на витрине не меняется ничего.
Потом, позиция за позицией и только с согласия владельца, содержимое подменяется нашим.

## Формат

YML (Yandex Market Language), UTF-8, с DOCTYPE. Ключ сопоставления товара — атрибут `id`
предложения, это **Артикул**. Он же стоит в конце адреса товара на сайте
(`.../abrikos_abakanskiy_zks-2903` → 2903) и в имени файла картинки (`2903-1.jpg`).

Цена и остаток остаются за 1С: значения в фиде справочные.

## Второй файл

`darwinshop-snapshot.xml` — замороженный снимок на момент начала работ. Нужен, чтобы
в любой момент можно было сравнить, что изменилось, или откатиться.
