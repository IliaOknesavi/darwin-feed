# Каталог питомника «Сажень» — управление описаниями на сайте

Здесь лежит файл, из которого сайт darwinshop.ru берёт описания товаров,
и всё, что нужно для его сборки.

**Ссылка, подключённая к сайту:** https://iliaoknesavi.github.io/darwin-feed/darwinshop.xml

---

## Как опубликовать наше описание сорта

1. Открыть файл **[approved.txt](approved.txt)** и нажать карандаш (Edit).
2. Найти нужный сорт — они по алфавиту.
3. Убрать решётку `#` в начале строки.
4. Нажать зелёную кнопку **Commit changes**.

Всё. Минут через пять фид пересоберётся сам, а сайт подхватит его в ближайшую ночь.

**Вернуть как было** — поставить решётку обратно тем же способом.

Пока строка с решёткой, на сайте остаётся описание из 1С, как сейчас.
В списке только те сорта, по которым материал написан и проверен, — сегодня их 131.

## Что здесь ещё

| | |
|---|---|
| `approved.txt` | Список сортов. **Единственный файл, который нужно трогать** |
| `darwinshop.xml` | Сам фид. Собирается автоматически, руками не редактируется |
| `darwinshop-snapshot.xml` | Снимок сайта на момент начала работ, для сравнения и отката |
| `cards/` | Наши описания сортов |
| `catalog/` | Слепок каталога сайта: цены, характеристики, картинки |
| `scripts/` | Сборка фида и добор новых позиций |

## Что происходит само

Раз в сутки, около десяти утра по Томску, автоматика обходит сайт, добирает
появившиеся товары и пересобирает фид. Позиция выходит на сайт, как только остаток
в 1С становится больше нуля, — так новинки попадают в фид без чьего-либо участия.

То же самое запускается сразу, как только кто-то правит `approved.txt`.

Посмотреть, что происходит, можно на вкладке **Actions**.

## Что остаётся за 1С и сюда не попадает

**Цена и остаток** — фид их не меняет, значения в нём справочные.

**Фасовка, доступность, скидка.** «Фасовка» на сайте работает переключателем вариантов
товара: у Авроры это 160 мл / Р9 / С3 с разными ценами. Передай мы одно значение —
переключатель исчезнет вместе с возможностью купить остальные фасовки. Доступность
и скидка — склад, они меняются ежедневно. Эти поля не трогаем никогда.
